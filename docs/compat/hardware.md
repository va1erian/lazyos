# Real-hardware compatibility

One row per physical machine that has run (or tried to run) the LazyOS USB
stick image ([`../usb-stick.md`](../usb-stick.md)). Honest rows beat a claim:
a failure with its last on-screen line is worth more than a blank.
The Linux ABI tables next to this file (`matrix.md`, `coverage.md`) are
generated by CI; this file is written by hand from a machine's boot report.

Columns: machine and year, firmware mode, CPU, RAM, framebuffer mode
(`HW:FB:` line), `HW:*` verdicts, what input worked, what failed, link to the
folder with the evidence.
