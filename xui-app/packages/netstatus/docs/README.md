# Network Status

Network status in the taskbar tray.

On a machine with a Wi-Fi radio the tray icon is a Wi-Fi fan: its lit parts are
the signal, a faded fan means not connected, a fan that fills step by step
means it is connecting, and a struck-through one means the radio is not
available. Hover for the network, signal and address. Click for the networks
in range: pick a saved or an open network to connect; a secured network you
have not used yet opens the Network app, where you type its password. The menu
also has Search again, Disconnect and Network settings.

A machine with only a cable shows the link icon and the address, as before.
