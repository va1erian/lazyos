# Files

Files browses folders and opens files with the app that handles their type (text in Editor, pictures in Paint, `.lzw` documents in LazyWriter, archives in Archiver, packages in the Package Installer).

Drag tiles out of a window to give them to another app (drop them on Archiver to put them in an archive), and drop files on a window to copy them into its folder: a name already there gets ` (2)`, and a folder is never copied into itself.
