# Calculator

A basic calculator that works like a pocket calculator: operations chain
from left to right as you press them (`12 + 7 × 3 =` gives `57`), and
pressing `=` again repeats the last operation.

## Keys

| Key | Does |
| --- | --- |
| `0`-`9`, `.` | Type a number (`,` also types the decimal point) |
| `+` `-` `*` `/` | Add, subtract, multiply, divide |
| `Enter` or `=` | Show the result; again to repeat the last operation |
| `%` | Percent: of the left number after `+` or `−`, else divide by 100 |
| `N` | Change the sign (`±`) |
| `Backspace` | Delete the last digit typed |
| `C` or `Delete` | Clear the number being typed (`C`), or everything (`AC`) |
| `Esc` | Clear everything |
| `Q` | Quit |

Dividing by zero shows `Error`; clear it or type a new number.
