LazyWeb

A small web browser for LazyOS, on the NetSurf engine.

Type an address in the bar above and press Enter, or try one of these:

  • http://example.com/
  • https://theoldnet.com/ — the web as it used to be

HTML and CSS are laid out by NetSurf; there is no JavaScript. Back and Forward: Alt+Left and Alt+Right. Reload: F5. Address bar: Ctrl+L.
