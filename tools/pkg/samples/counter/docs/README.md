# Packaged Counter

The Counter demo, installed from a package (`org.lazy.counter`). It runs in
its own sandbox: it may only talk to the compositor and the input service,
which is everything a window needs.

`pkgd` copied this page from the package's `docs/` to
`/docs/apps/org.lazy.counter/` when it installed the app, and deletes it again
when the app is removed. Open it from the Docs app.
